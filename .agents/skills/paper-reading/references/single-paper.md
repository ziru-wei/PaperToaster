# Single-paper Reading

Search the supplied paper file with distinctive terms from the current question. If direct terms miss, inspect its Markdown headings and search relevant synonyms. Read contiguous passages around matches, including nearby headings and paragraphs; do not rely on isolated matching lines. Search additional sections when the first passage does not resolve the question.

When selected text is supplied, use distinctive wording from it as a file-search anchor, then inspect its surrounding passage. For a selected-text question:

- Explain the selected passage's local meaning first, in plain language before any technical restatement.
- Use nearby context to resolve terms, references, equations, or argumentative role.
- Define unfamiliar terms, acronyms, or notation where doing so is necessary to follow the explanation.
- Connect the passage to the paper-level claim only when the supplied evidence supports that connection.

For a targeted question, synthesize the file sections that address it. Do not turn the response into a whole-paper summary. Match explanation depth to the scope of the question rather than defaulting to a full section-by-section treatment.

For a broad overview, inspect Abstract/Introduction, Method, Results, Discussion/Limitations, and Conclusion when present. Distinguish the research problem, contribution, approach, evidence, and limitations when available. Use compact headings or labeled points for sufficiently broad answers; do not force them for narrower answers.
